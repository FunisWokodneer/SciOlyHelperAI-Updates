# SciOlyHelperAI Updates

This public repository is reserved for official SciOlyHelperAI application releases and update-feed assets.

- The application source code is maintained separately in a private repository.
- Release packages and Velopack feed metadata will be published here.
- Do not upload source code, personal information, preparation tasks, or workspace data.
- Only stable, tested releases should be published.

The updater checks this repository for releases. No personal GitHub token is required by the app.

**Releases are not published yet.** Until a tested release appears under [Releases](https://github.com/FunisWokodneer/SciOlyHelperAI-Updates/releases), the in-app update check may report that no update feed is available.
